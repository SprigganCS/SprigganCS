## Research

I work on **Unsupervised Domain Adaptation (UDA) for object detection**: making detectors
trained on labeled data hold up on a target domain where no annotations are available. My
interests include the interaction between pixel-level and feature-level adaptation, the
reliability of pseudo-labels under domain shift, and diagnosing when image translation
preserves the semantics that supervision depends on.

Sim-to-real transfer was the setting of my master's work, and remains one instance of the
broader problem rather than the object of it.

`Domain Adaptation` &nbsp;`Object Detection` &nbsp;`Computer Vision` &nbsp;`Deep Learning`
